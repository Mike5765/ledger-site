# ledger-site

Public pages for Ledger, a personal dashboard that runs only on its owner's Mac:
the homepage, privacy policy, and terms of service required for Google's OAuth
consent screen branding.

Served by GitHub Pages at https://ledger.denaliops.ai.

This repository holds only these static pages. Ledger's own code is not here.

The font is Plus Jakarta Sans, under the SIL Open Font License (`fonts/OFL.txt`).
